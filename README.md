# 🎬 YT Video Downloader

A fast, reliable, and modern **YouTube Video Downloader for Windows** with a clean GUI and auto-update support.

Download YouTube videos, playlists, and audio in high quality with pause/resume support and smart handling of internet disconnects.

---

## 🚀 Features

- 📥 Download YouTube videos in **420p / 720p / 1080p**
- 🎧 **High-quality MP3 audio** download
- ⏸ **Auto-pause** when internet disconnects
- ▶️ **Resume download** anytime
- 🚀 Multi-threaded downloading for better speed
- 🔄 **Auto-update for yt-dlp backend** (runs silently every 24 hours)
- 🆕 Built-in **App Auto-Update System**
- 🌙 Modern **Dark UI** built with `ttkbootstrap`
- 📝 Clean logging system (stored in `AppData/Roaming`)
- 📂 One-time folder selection per session
